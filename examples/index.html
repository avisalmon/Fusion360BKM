How every example is made

  • examples/NN_name/design.py builds it from a clean document (python scripts\fusion.py run examples\NN_name\design.py) and ends with a result of bodies, bounding boxes and parameters; media/ the screenshots; index.html the page; <name>.f3d the archive.
  • Everything goes through scripts/fusion.py and the CopilotBridge add-in running inside Fusion; the helpers in CopilotBridge/bridge_helpers.py take and report millimetres.
  • An example is marked verified only after a run whose numbers matched the spec and a screenshot that was looked at; the badge says when and in which Fusion version. Printing is recorded only when a print was made and measured.
  • Each example also teaches the repo something: a helper, a reference fact, a gotcha, a skill update. That is written on its page.
